# AWS Secure VPC Architecture Project

## Project Overview

This project demonstrates the implementation of a secure AWS VPC architecture using public and private subnets.

The infrastructure includes:

- Custom VPC
- Public Subnet
- Private Subnet
- Internet Gateway
- NAT Gateway
- Public Route Table
- Private Route Table

This setup simulates a real-world enterprise cloud networking environment.

## Features Implemented

- Secure public/private subnet separation
- Internet access through Internet Gateway
- Secure outbound internet for private subnet via NAT Gateway
- Custom route table associations
- Enterprise-style network segmentation
